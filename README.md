# nosAI Modules
AI related modules for Nodos.

## Build
### Dependencies
- CUDA SDK 12.8
- CUDNN SDK 9.7
- TensorRT SDK 10.8 for CUDA 12.8
- OnnxRuntime SDK 1.20

`CUDA_PATH`, `CUDNN_SDK_PATH`, `TENSORRT_SDK_PATH`, `ONNX_SDK_PATH` variables must be present in the form of environment variables or can be passed as cmake arguments.
