# nosCUDA Modules
CUDA related modules for Nodos.

## Build
### Dependencies
- CUDA SDK 12.8

`CUDA_PATH` variable must be present in the form of environment variables or can be passed as cmake arguments.

`nosCUDADeps` submodule contains the nodos Plugin of CUDA runtime dependencies. It can be downloaded in nodos with the name `nos.sys.cuda.deps`
